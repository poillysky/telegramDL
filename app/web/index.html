Telegram 登录

凭证来自 my.telegram.org ；登录后会保存，服务重启可自动重连。

API 手机 验证

需要时再填；国内网络不稳可配 Clash SOCKS5。

网络代理

可选；留空为直连。保存后写入本地配置，重启仍生效。

多任务并行

同时运行的下载任务（不同群）上限；同任务内并发仍由「并发下载」控制。

下载连接 / 吞吐

媒体 DC 连接数与分块流水线。代理环境可适当提高；出现 FloodWait 请立刻降回 3 / 4。保存后对新下载立即生效。

自动重试 / 限流

失败文件定时再试、监控心跳、单次 FloodWait 最长等待。保存后对后续等待/重试立即生效。

完成 / 限流通知

Webhook：任务完成、失败或 FloodWait 时 POST JSON；留空则不发送。

关联黑名单

不参与「关联」聚合，也不进多标签文件夹名。适合网红 / 福利等通用词。
